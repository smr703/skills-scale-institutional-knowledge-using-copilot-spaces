# OctoAcme Project Management Documentation

Welcome to the central landing page for OctoAcme's project management documentation. This collection of process docs covers everything teams need to plan, execute, and continuously improve the delivery of product features, services, and integrations.

## Overview

OctoAcme follows a structured, iterative project management approach guided by these core principles:

- **Customer-first**: prioritize customer value and usability in every decision.
- **Iterative delivery**: ship small, testable increments and adjust based on feedback.
- **Clear ownership**: every project has a named Project Manager (PM) and Product Lead.
- **Data-informed decisions**: measure impact and iterate based on evidence.
- **Psychological safety**: encourage open feedback and continuous learning.

Projects move through five lifecycle stages — **Initiation → Planning → Execution → Release → Retrospective** — with defined roles, artifacts, and communication cadences at each stage.

## Getting Started

If you are new to OctoAcme, start with the [Project Management Overview](octoacme-project-management-overview.md) to understand the approach and key artifacts, then follow the lifecycle documents in order as your project progresses.

> **Tip:** Add relevant process docs to `.copilot/` in your project repo to give Copilot Spaces the context it needs to provide role-specific guidance.
