# OctoAcme Project Management Documentation

This repository centralizes OctoAcme project management knowledge so teams can explore, reuse, and improve shared processes with Copilot Spaces.

## Purpose

The documentation in this repository helps teams:

- standardize project workflows
- reduce reliance on tribal knowledge
- support onboarding
- make project decisions and processes easier to find
- provide structured context for Copilot Spaces

## Repository Contents

This repository includes:

- **8 project management documents** in `docs/`

## Project Management Process Summary

OctoAcme follows a structured delivery lifecycle:

1. **Initiation** — define the problem, stakeholders, success metrics, and go/no-go decision
2. **Planning** — create backlog, estimates, milestones, dependencies, and definition of done
3. **Execution & Tracking** — manage day-to-day delivery, reviews, testing, and progress reporting
4. **Risk Management & Communication** — identify, assess, communicate, and escalate risks
5. **Release & Deployment** — prepare, deploy, verify, and communicate releases
6. **Retrospective & Continuous Improvement** — capture lessons learned and track improvement actions

In addition to the lifecycle documents, this repo also includes:
- **Project Management Overview** — a high-level summary of principles, roles, artifacts, and communication cadence
- **Roles and Personas** — definitions for Developers, Product Managers, and Project Managers
